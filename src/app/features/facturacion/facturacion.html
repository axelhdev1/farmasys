Facturación Electrónica

Integración con SUNAT vía OSE para boletas y facturas electrónicas

receipt_long

Emisión automática de comprobantes electrónicos

Este módulo conectará FarmaSys directamente con SUNAT a través de un Operador de Servicios Electrónicos (OSE). Cada venta del POS generará automáticamente una boleta o factura electrónica válida, firmada digitalmente y registrada en SUNAT en tiempo real.

¿Qué se necesita para activar este módulo?

Dos pasos independientes — cada uno con su propio costo

①

Contratar un OSE

Costo mensual del negocio

El cliente contrata directamente un Operador de Servicios Electrónicos autorizado por SUNAT. El OSE se encarga de validar y enviar los comprobantes a SUNAT.

OSE recomendados

Nubefact Desde S/ 39/mes
Efact Desde S/ 35/mes
SUNAT (SOL) Gratuito*

*SUNAT gratuito no recomendado para alto volumen — puede ser lento e inestable.

info

Este costo lo paga el cliente directamente al OSE. No pasa por el desarrollador.

②

Desarrollo de la integración

Cotización aparte — pago único

El desarrollador conecta FarmaSys con la API del OSE elegido. Incluye generación del XML (formato UBL 2.1), envío automático desde el POS y almacenamiento del CDR de cada comprobante.

Obligación legal vigente

Según la normativa SUNAT, los negocios con RUC activo están obligados a emitir comprobantes electrónicos. Operar sin este módulo activo implica riesgo de multas por parte de SUNAT y observaciones de DIGEMID en inspecciones. Este módulo debe activarse antes de poner el sistema en producción.
